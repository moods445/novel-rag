      设置

      人名识别

      jieba 走本地词性标注（CPU、约 5MB 词典），配合「姓X名Y字Z」规则能得到别名对； 正则模式零依赖但召回较低。

      章节识别

      规则优先，置信度不足时才调 LLM；也可以强制总是用 LLM。

      抽取分段

      每次 LLM 抽取的原文目标长度。分段数按 ceil(总字数 / 该值) 向上取整， 再把总字数均分到各段，避免最后一段只剩十几个字。

      语义检索（embedding）
      模型下载源

      默认自动：先直连 HuggingFace，失败后自动切换国内镜像；也可固定某一源。

      推理模型

      provider 只有「设置页添加」这一个来源（保存在本机数据库），抽取与查询共用同一个模型； 也可以用环境变量 NOVEL_RAG_QUERY_* 直接指定。未配置时退回离线模式： 抽取用启发式、问答用原文摘录。
